# Electrochemical sensing and machine olfaction

Access the course site here: https://kordelfrancetech.github.io/Machine-Olfaction-Course/


A university-level engineering curriculum that follows a molecule from its environment through sampling, interfacial chemistry, electrical measurement, statistical inference, and a defensible decision.

**Start with the [course home](docs/index.md), [module directory](docs/modules/index.md), or [site map](docs/navigation.md).**

The course is designed for senior undergraduate students, beginning graduate students, and engineers entering chemical sensing from another discipline. It combines chemical engineering, electrochemistry, instrumentation, statistics, and machine learning. A learner with stronger preparation in one area can use the prerequisite links to enter another area without assuming that electronics, chemistry, and machine learning share the same vocabulary.

## How to read the material

Each module moves from an intuitive question to an explicit model, then tests where that model fails. Exercises ask for numerical answers and an explanation of whether the answer is meaningful. Experimental and clinical results are attributed to their original public sources. Teaching examples use invented parameters and are labeled accordingly; they are not measurements from a commercial device.

All curriculum and maintainer documents are Markdown. Four support files enable the requested Minima theme: `docs/_config.yml`, `docs/assets/main.scss`, and header/footer includes in `docs/_includes/`. Code and data needed for the introductory labs appear inside Markdown code blocks and tables. Equations use text notation that remains legible without a JavaScript mathematics renderer. Navigation uses relative Markdown links, suitable for reading in a repository and for conversion by GitHub Pages. Every learner page has a common menu, breadcrumbs where applicable, and return links. Long pages have collapsible contents; modules, labs, and project lessons have previous/next links. The module, lab, project, and library hubs support both sequential study and topic browsing.

## Publication boundary

`docs/` is the complete learner-facing publication directory. For the cleanest release, copy only `docs/` into a new publishing repository and select that repository's `/docs` directory as the Pages source. The maintainer documents in this directory can remain local. There is no requirement to copy the enclosing workspace.

Nothing has been uploaded, committed, or deployed by preparing this curriculum. Private repository visibility and private website access are separate settings; follow [PUBLISHING.md](PUBLISHING.md) before enabling hosting.

The material explains public scientific principles. It does not specify a commercial formulation, a product's operating settings, or a production manufacturing process. No open-source license or redistribution rights have been assigned to the original course text; the owner can choose those separately. External publications and datasets retain their own terms.

Research checked: **22 November 2026**. This is a curated educational synthesis, not an exhaustive systematic review or a claim that every cited technology has achieved field deployment.
