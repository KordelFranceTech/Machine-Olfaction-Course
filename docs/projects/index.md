Choose a useful question, then select a documented educational platform, an authorized commercial module, or an original computational model that can answer it. A coherent project has explicit interfaces and acceptance tests; it does not need every sensing subsystem taught in the course.

<a id="section-a-guided-project-path"></a>

## A guided project path

| Step | Page | What you produce |
| --- | --- | --- |
| 1. Define the question | [Design studio](../design-studio.md) | A measurement contract, alternatives, and applicable design decisions |
| 2. Connect the quantities | [Integrated worked example](../integrated-example.md) | Unit-consistent input, transduction, readout, and quality-state interfaces |
| 3. Plan a bounded demonstration | [Build ladder](../build-ladder.md) | A staged verification plan, beginning with simulation or passive circuits |
| 4. Select an original contribution | [Nine nearby projects](../derivative-projects.md) | A useful scope, public basis, build plan, and acceptance tests |
| 5. Document provenance | [Responsible innovation](../responsible-innovation.md) | Sources, permissions, independent contributions, and review status |
| 6. Defend the result | [Capstone lab](../labs/08-capstone-studio.md) | A reproducible dossier and requirements-to-test matrix |

The worked example is synthetic. Completing it demonstrates the stated model's behavior, not a physical sensor's performance. The nearby projects are proposals with unassessed clearance status, not guarantees of permission to commercialize a design.

<a id="section-choose-by-the-resources-you-have"></a>

## Choose by the resources you have

| Available resources | A useful starting point |
| --- | --- |
| Computer only | Calibration/drift workbench, transport simulator, materials-evidence explorer, or active-sampling simulator |
| Teaching electronics bench | Passive impedance kit and documented readout experiments |
| Purchased environmental modules | Ambient logging or humidity-response characterization within documented operating limits |
| Supervised teaching chemistry laboratory | Conductivity metrology with approved standards and procedures |

Find detailed project cards in [Nearby projects](../derivative-projects.md). For any selected project, report which results were calculated, simulated, measured, or inferred from literature.

<a id="section-prepare-for-review"></a>

## Prepare for review

Use the [assessment rubrics](../assessments/index.md) and the [system-design module](../modules/18-system-design-and-responsible-use.md). If the project depends on uncertain materials or clinical assumptions, narrow the demonstrated result and record the additional evidence required.
